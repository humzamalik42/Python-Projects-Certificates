Financial Chatbot Prototype Using Python
This project showcases the development of a simplified AI-powered financial chatbot that responds to predefined queries based on analyzed financial data. 
The project is divided into two main parts: data analysis and chatbot development. Using Python and pandas, I extracted and processed financial data from 10-K reports to calculate key metrics like revenue growth and net income growth. 
The chatbot logic uses rule-based if-else statements to respond to queries, offering insights derived from the financial data. 
This project demonstrates how AI can be used to translate complex financial data into accessible and user-friendly insights.
